# Project configuration (schema 2.0)

Start from the `project.json` generated by `extract_emfoundation_embeddings.py`. JSON is preferred; YAML requires PyYAML.

## `project`

- `id`: stable run identifier.
- `purpose`: annotation goal and target ontology.

## `source`

- `uri`: absolute or immutable source location.
- `axes`: exactly `zyx` at the selector boundary.
- `shape_zyx`, `voxel_size_nm_zyx`, `dtype`, `source_sha256`: audited source identity and geometry.
- Bounding boxes everywhere are half-open `[[z0,y0,x0],[z1,y1,x1]]`.

## `embedding`

- `model_repository`, `model_commit`, `checkpoint_name`, `checkpoint_sha256`: model provenance.
- `dimension`: 512 for the audited EMFoundation BASE adapter.
- `normalization`: exact intensity transform.

## `tiling`

- `patch_shape_zyx`, `stride_zyx`: must match embedding extraction.
- `boundary_mode`: `valid` or `align_end`; `reflect` is accepted by the planner only when an external adapter reproduces identical padding.

## `selection`

- `candidate_windows_patches_zyx`: non-empty list of contiguous patch-grid windows. Example: `[[1,3,3],[1,5,5],[2,3,3],[2,5,5]]`.
- `expected_subvolume_shapes_zyx`: optional hard check. Each shape equals `patch + stride × (window − 1)`.
- `annotation_budget_voxels`: maximum sum of selected source-voxel bbox volumes.
- `max_subvolumes`: upper bound on selected boxes.
- `k_neighbors`: embedding neighborhood size, including the query patch.
- `metric`: `euclidean` or `cosine`.
- `cost_exponent`: value in `[0,1]`. The greedy score is `marginal_gain / cost^cost_exponent`.
- `disallow_patch_overlap`: normally true.
- `max_exact_patches`: explicit gate before O(N²) exact KNN.
- `max_working_memory_mib`: distance-block memory cap; it does not change quadratic time.

Use actual annotation time when available. Voxel count is only a reproducible proxy and may not reflect neurite complexity, artifacts, or annotator effort.

## `guards`

- `excluded_bboxes_zyx`: artifacts, missing tissue, already-labeled or forbidden regions.
- `holdout_bboxes_zyx`: validation/test regions that may never enter the queue.
- Expand holdout boxes before planning when a spatial split gap is required.

## Embedding order contract

Row `i` of `embeddings.npy` must equal patch `i` in `candidates.json`. Pass `positions_zyx.npy` to `select`; selection fails unless its rows exactly match `patches[*].bbox_zyx[0]`.

## Legacy compatibility

Schema 2.0 can read a single legacy `window_patches_zyx` plus `budget_subvolumes`, but this is fixed-size mode. New real-data runs must use the multi-scale list and voxel budget.
